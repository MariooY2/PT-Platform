## Harness notes
- Lesson: in Next 16 App Router, a Server Component must not pass a component reference (e.g. a lucide
  icon) as a prop to a Client Component — it fails the production build ("Functions cannot be passed
  directly to Client Components"), which the fast verify does not catch but `verify --full` (build) does.
  Pass a serializable key and let the client island import the data. Worth a lessons.md entry.
